## Install Notes
1. Go to Joomla Administrator.
2. Open System -> Install -> Extensions.
3. Upload the ZIP package for your Joomla major version.
4. Activate Malay language in System -> Manage -> Languages.

## Build Notes
- Build script: ./build.ps1
- Config file: build/build.config.json
- Output folder: dist

## Compatibility
- pkg_ms-MY_j5.zip is intended for Joomla 5.x.
- pkg_ms-MY_j6.zip is intended for Joomla 6.x.
