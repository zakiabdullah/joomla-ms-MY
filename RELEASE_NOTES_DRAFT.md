# Release 5.4.10v1

Malay (ms-MY) language pack for **Joomla 5.4.10** and **Joomla 6.2.0**.

## Highlights
- 100 % key coverage against Joomla `5.4-dev` and `6.2-dev`, including early
  translations for strings coming in Joomla 6.2.1.
- Joomla 6 package now uses the Joomla 6 forms of strings whose placeholders changed
  (uninstall messages, accessible media labels), so no information is lost on Joomla 6.
- Link `title` attributes in action log, privacy and consent messages (Joomla 6.2 accessibility change).
- Consistent terminology across the pack. See `GLOSSARY.md`.
- New automated translation QA in CI (format, duplicates, placeholders, parity with en-GB).

See `CHANGELOG.md` for the full list.

## Install
1. Download the package that matches your Joomla major version.
2. In Joomla Administrator open **System → Install → Extensions** and upload the ZIP.
3. Enable Malay in **System → Manage → Languages**.

Existing installations are updated automatically through the Joomla Update Directory.
